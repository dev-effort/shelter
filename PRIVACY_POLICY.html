SHELTER

개인정보 처리방침
최종 업데이트: 2025년 1월 15일

SHELTER("본 앱")는 사용자의 개인정보를 소중히 여기며, 개인정보보호법 및 관련 법규를 준수합니다. 본 개인정보 처리방침은 본 앱이 어떻게 사용자 정보를 수집, 사용, 보호하는지 설명합니다.

1. 수집하는 정보

1.1 직접 수집하는 정보

본 앱은 다음과 같은 정보를 수집하지 않습니다:

  • 이름, 이메일, 전화번호 등 개인 식별 정보
  • 위치 정보
  • 연락처 정보
  • 사진, 미디어 파일
  • 계정 정보

1.2 사용자가 생성하는 데이터

사용자가 본 앱에서 생성하는 다음 데이터는 기기 내부에만 저장됩니다:

  • 저장한 웹 링크 (URL, 제목, 설명)
  • 폴더 구조
  • 태그
  • 메모 및 설명
중요: 이 모든 데이터는 사용자의 기기에만 저장되며, 외부 서버로 전송되지 않습니다.

2. 정보의 사용 목적

본 앱은 수집한 정보를 다음 목적으로만 사용합니다:

  • 링크 저장 및 관리 기능 제공
  • 폴더 및 태그 기능 제공
  • 검색 기능 제공
  • 앱 성능 개선

3. 광고

3.1 Google AdMob

본 앱은 Google AdMob을 사용하여 광고를 표시합니다. AdMob은 광고 제공을 위해 다음 정보를 수집할 수 있습니다:

수집되는 정보:

  • 광고 ID (Advertising ID)
  • IP 주소
  • 기기 정보 (기기 모델, OS 버전)
  • 앱 사용 정보
  • 광고 상호작용 정보

수집 목적:

  • 맞춤형 광고 제공
  • 광고 성과 측정
  • 사기 및 남용 방지

3.2 광고 개인정보 보호

사용자는 다음 방법으로 광고 추적을 관리할 수 있습니다:

Android:

  1. 설정 → Google → 광고
  2. "광고 맞춤설정 선택 해제" 활성화

Google 개인정보 처리방침:

  • https://policies.google.com/privacy
  • https://policies.google.com/technologies/ads

4. 데이터 저장 및 보안

4.1 로컬 저장

  • 모든 사용자 데이터는 기기의 로컬 저장소에 저장됩니다
  • SQLite 데이터베이스를 사용합니다
  • 외부 서버로 전송되지 않습니다

4.2 보안

  • 데이터는 기기의 앱 전용 영역에 저장됩니다
  • 다른 앱에서 접근할 수 없습니다
  • 앱 삭제 시 모든 데이터가 함께 삭제됩니다

4.3 백업

  • 사용자가 Android 백업을 활성화한 경우, 앱 데이터가 Google 계정에 백업될 수 있습니다
  • 이는 Android 시스템 설정에서 관리할 수 있습니다

5. 데이터 공유

본 앱은 사용자 데이터를 제3자와 공유하지 않습니다. 단, 다음의 경우 예외입니다:

5.1 광고 서비스

  • Google AdMob이 광고 제공을 위해 위 3항에 명시된 정보를 수집할 수 있습니다

5.2 법적 요구

  • 법적 의무를 준수하기 위해 필요한 경우
  • 사기 또는 보안 문제 대응

6. 사용자 권리

6.1 데이터 삭제

  • 앱 내에서 언제든지 저장한 링크, 폴더, 태그를 삭제할 수 있습니다
  • 앱을 삭제하면 모든 데이터가 기기에서 완전히 제거됩니다

6.2 데이터 이전

  • 사용자의 모든 데이터는 로컬에 저장되므로, 직접 관리할 수 있습니다

6.3 문의 및 요청

  • 개인정보와 관련된 문의는 아래 연락처로 연락 주시기 바랍니다

7. 어린이 개인정보 보호

본 앱은 13세 미만의 어린이를 대상으로 하지 않으며, 의도적으로 어린이의 개인정보를 수집하지 않습니다. 만약 부모님이나 보호자께서 자녀가 개인정보를 제공했다고 판단되시면, 즉시 연락 주시기 바랍니다.

8. 개인정보 보유 기간

  • 사용자가 앱을 사용하는 동안 데이터가 기기에 보관됩니다
  • 앱 삭제 시 모든 데이터가 즉시 삭제됩니다
  • 외부 서버에 데이터를 보관하지 않습니다

9. 국제 데이터 전송

본 앱은 데이터를 외부 서버로 전송하지 않습니다. 다만, Google AdMob 서비스는 Google의 서버를 통해 처리될 수 있으며, 이는 Google의 개인정보 처리방침을 따릅니다.

10. 정책 변경

본 개인정보 처리방침은 필요에 따라 변경될 수 있습니다. 중요한 변경사항이 있을 경우:

  • 앱 업데이트를 통해 사용자에게 알립니다
  • 이 페이지에 변경 내용을 게시합니다
  • 최종 업데이트 날짜를 갱신합니다

변경된 정책은 게시 즉시 효력이 발생합니다.

11. 사용 권한

본 앱이 요청하는 권한과 그 목적:

11.1 인터넷 (INTERNET)

  • 목적: 광고 표시
  • 필수 여부: 필수

11.2 기타 권한

본 앱은 위 권한 외에 추가 권한을 요청하지 않습니다.

12. 타사 서비스

본 앱은 다음 타사 서비스를 사용합니다:

Google AdMob

  • 제공: Google LLC
  • 목적: 광고 표시
  • 개인정보 처리방침: https://policies.google.com/privacy

13. 연락처

개인정보 처리방침 또는 앱에 관한 질문이나 우려사항이 있으시면 아래로 연락 주시기 바랍니다:

이메일: [여기에 이메일 주소 입력]

앱 이름: SHELTER

개발자: [여기에 이름 또는 회사명 입력]

14. 준거법

본 개인정보 처리방침은 대한민국 법률에 따라 해석되고 적용됩니다.

요약

  • ✅ 수집하지 않는 정보: 이름, 이메일, 전화번호, 위치 정보
  • ✅ 로컬 저장: 모든 데이터는 기기에만 저장
  • ✅ 광고: Google AdMob 사용 (광고 ID, IP 주소 등)
  • ✅ 외부 전송 없음: 데이터가 외부 서버로 전송되지 않음
  • ✅ 언제든 삭제 가능: 앱 삭제 시 모든 데이터 제거

본 개인정보 처리방침에 동의하시면 본 앱을 계속 사용하실 수 있습니다.
