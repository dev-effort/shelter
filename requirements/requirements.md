# 사용하는 기술 스택

ionic, react19, typescript, shardcn

# 앱 이름

shelter

# 앱의 기본 기능 및 컨셉

shelter앱은 많은 링크(url) 정보를 카테고리화하여 저장하는 앱이다.
shelter앱은 폴더구조를 가지고 있다. 폴더들은 계층구조를 가진다.
폴더구조에 저장되는 메타정보는 제목, url, 설명, 태그이다.
태그로 필터링 하여 볼 수 있다.
url을 누르면 해당 url을 켤 수 있는 인앱이 있으면 앱을 먼저 키고 없으면 브라우저로 연다.
외부앱 (유튜브, 인스타그램 등)에서 외부앱으로 공유하기를 했을때, shelter앱이 나오고, shelter앱을 선택하면 폴더를 선택하거나, 폴더를 생성하고 선택된 폴더에 제목과 공유된 링크, 설명을 저장한다.

# 화면 구조

- 위에서부터 아래로 4개의 영역
- 구글 ad
- header: 폴더생성 버튼, 문서 생성 버튼
- body
- navigation: 홈, 태그, 검색, 설정

# 상세 페이지 구조

- 홈: 리스트 구조 또는 그리드 구조로 폴더와 문서들을 보여줌. 폴더안에 몇개의 링크와 몇개의 폴더가 있는지 메타 정보를 보여준다. 클릭하면 폴더 상세로 이동한다. item을 길게 누르면 삭제에 대한 팝업을 띄워준다.
- 문서 상세: 제목, 링크 url, 설명, 태그들의 정보를 가지고 있다.
- 태그: 태그들의 목록이 보이고 태그들을 클릭하면 해당 태그들을 가지고 있는 문서들이 나온다.
- 검색: 검색 화면이 나오고 검색하면 조건에 만족하는 문서들이 나온다.
- 설정: 앱 버전이 나온다.리스트 구조 또는 그리드 구조를 설정할 수 있다.
